Чтобы узнать свой ключ API, нужно запустить программу get_token.py
    Предусловие запуска: Написать свою почту, пароль и id компании

Чтобы передать ключ, нужно вписать его в начале файла test_project_yougile.py в переменную API_KEY

Все зависимости устанавливаются командой pip install -r requirements.txt

в файле pytest.ini хранятся маркеры, для того, чтобы pytest не выдавал мне варны (ошибки)
